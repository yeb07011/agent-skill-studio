# Roadmap

Agent Skill Studio is intentionally small today. The project is designed to grow in practical layers.

## Now

- Template-based generation
- CLI
- Browser-only Web UI
- Skill linter
- Multi-target package output
- Export manifest

## Next

- OpenAI-compatible provider interface implementation
- Import from existing prompt files, SOPs, and agent rules
- Downloadable zip bundles from the Web UI
- Skill diff and version comparison
- Stronger safety linting for tool permissions
- More templates for engineering, product, design, research, and content workflows

## Later

- Skill registry metadata
- Team template packs
- GitHub repo scanner for existing agent instructions
- Marketplace preview pages
- Cross-tool compatibility tests
- Optional human-review workflow generation
